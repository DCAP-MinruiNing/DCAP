About DCAP

The Daily CV Alert Project (DCAP) is the pipeline for analyzing the public ZTF alert stream.

We will release manually screened ZTF transient targets; typically, only those classified as unknown at the time of classification will be published. If a target is already known, it will be noted in the remarks.

If you publish to TNS using DCAP's classification, you can note that you used DCAP (or not) — it's up to you. DCAP's goal is to help confirm discoveries faster.

A five-layer degrading-hierarchy pipeline that automatically rejects known asteroids and high proper-motion stars from ZTF alerts before TNS reporting.
